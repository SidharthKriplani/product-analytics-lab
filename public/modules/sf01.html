What is Data?

Variables, types, and the measurement foundation

Your PM asks why the experiment dashboard shows DAU for one metric but a percentage for another. The answer starts with data types — because every metric you measure is a variable, and the type determines how you analyze it. A/B tests measure both kinds: numerical variables like revenue per user or session length, and categorical ones like converted-or-not and clicked-or-not, which become proportions. The type you have decides which test you run.

How this connects to experimentation: When you define a metric in an experiment, you are choosing a variable to measure on each observation (user or session): a numerical one like revenue per user, or a categorical one like conversion or click, which you summarize as a proportion.

Key takeaways

  • Every metric is a variable, and its type decides which test you run.
  • A/B tests measure numerical variables (revenue, session length) and categorical ones (converted?, clicked?) as proportions.
  • Get the type right first — everything downstream depends on it.

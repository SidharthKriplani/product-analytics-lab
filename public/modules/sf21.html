Counterfactuals & Causal Inference

Why you can't infer causation from correlation — and what makes an A/B test different

Users who use the mobile app have 40% higher retention than those on desktop. The data team proposes investing in the mobile app to improve retention. Before you write the spec, you need to ask: would those same users have retained less if they'd used desktop? You can never run both timelines for the same user. The fundamental problem of causal inference is that you can never observe both outcomes for the same unit — and A/B tests solve this by creating a group that IS the counterfactual through random assignment.

How this connects to experimentation: Every non-experimental comparison — observational data, before/after, top vs. bottom users — has a confounding risk. Randomization is what makes the A/B test result actionable.

Key takeaways

  • The fundamental problem: you can never observe both outcomes for the same unit.
  • Mobile users retaining better than desktop users could be who they are, not the platform.
  • A/B tests create a group that is the counterfactual via random assignment.
